# TRGB · nieuwe website (demo)

Demo van de nieuwe site voor Tennis- en Recreatieclub Groot-Bijgaarden (TRGB).
Statische site: HTML, CSS en JavaScript, zonder framework. Online via GitHub Pages.

- `index.html`, `spelen.html`, `jeugd.html`, `lid-worden.html`, `kalender.html`, `club.html`, `privacy.html`, `404.html`
- `css/site.css` stijl en tokens, `js/` scripts, `assets/` logo, foto's en sponsorlogo's
- `brand-spec.md` ontwerpbeslissingen en assets

Lokaal bekijken: serveer de map met een webserver (bijvoorbeeld `python3 -m http.server`), niet via `file://`, want het 3D-terrein gebruikt ES-modules.
